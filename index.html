タブ音声 文字起こし

ブラウザのタブで再生している動画の音声を、その場で文字にします。音声はこのPCの中だけで処理し、外部には送りません。

このブラウザではタブの音声を取り込めません。Google Chrome または Microsoft Edge（パソコン版）で開いてください。

使い方

  1. 文字にしたい動画（YouTubeなど）を、別のタブで開いておきます。
  2. 「タブを選んで開始」を押します。初回はモデルのダウンロードに数分かかります。
  3. 共有画面で Chrome タブ（Edgeは タブ）を選び、動画のタブをクリックします。
  4. タブの音声も共有する がオンになっていることを確かめて、共有 を押します。
  5. 動画を再生すると、区切りごとに文字が追加されます。終わったら「停止」を押します。

モデルは2回目以降ブラウザに保存されたものを使うので、すぐ始まります。パソコンの性能が低い場合は base を選んでください。
